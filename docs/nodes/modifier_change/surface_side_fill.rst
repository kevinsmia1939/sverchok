Surface Side Fill
=================

Functionality
-------------

This node fills one side of an input surface mesh. It is intended for surfaces
that divide a volume into two regions, for example an isosurface generated by
the :doc:`Marching Cubes </nodes/surface/marching_cubes>` node.

The node builds a temporary volumetric grid over the supplied bounds, classifies
each cell against the input surface with Blender's BVH tree, then emits the
exposed voxel faces of the selected volume. This keeps the implementation local
to Sverchok and avoids the PyVista / VTK path that was used previously.

The result is not a simple hole cap. It is a generated volume-side boundary,
including the selected side of the input surface and the outer boundary faces
where the generated volume meets the bounding box.

Dependencies
------------

This node uses Sverchok's own geometry helpers and does not require external
surface extraction packages.

Inputs
------

- **Vertices**. Vertices of the input surface mesh.
- **Faces**. Faces of the input surface mesh.
- **Bounds**. Optional vertices used to define the fill volume bounds. When not
  connected, the node uses the bounds of the input surface vertices.
- **Samples X**. Number of grid samples along X.
- **Samples Y**. Number of grid samples along Y.
- **Samples Z**. Number of grid samples along Z.
- **Padding**. Relative padding added to automatically calculated bounds.

Parameters
----------

+-------------------+---------+-----------+--------------------------------------------------------------+
| Param             | Type    | Default   | Description                                                  |
+===================+=========+===========+==============================================================+
| **Side**          | Enum    | Inside    | Selects which side of the surface to fill.                   |
+-------------------+---------+-----------+--------------------------------------------------------------+
| **Flip Side**     | Bool    | False     | Reverses the selected side.                                  |
+-------------------+---------+-----------+--------------------------------------------------------------+
| **List Match**    | Enum    | Repeat    | Behavior on different input list lengths.                    |
+-------------------+---------+-----------+--------------------------------------------------------------+

Outputs
-------

- **Vertices**. Vertices of the filled side mesh.
- **Edges**. Edges of the filled side mesh.
- **Polygons**. Faces of the filled side mesh.

Usage Notes
-----------

For Marching Cubes workflows, connect:

- Marching Cubes **Vertices** to this node's **Vertices** input.
- Marching Cubes **Faces** to this node's **Faces** input.
- The same bounds geometry used by Marching Cubes to this node's **Bounds**
  input.

Using the same bounds for both nodes gives a predictable fill volume. If Bounds
is not connected, use **Padding** when the surface touches the automatically
calculated bounding box.

Higher **Samples X/Y/Z** values make the generated side boundary more detailed,
but also increase processing time. The result is voxel-based, so the mesh gets
more detailed as the sample count increases.

Examples of Usage
-----------------

Use this node after Marching Cubes to turn one side of an implicit surface into
a filled mesh region. For TPMS-style surfaces, **Inside** and **Outside** can
be used to select one of the two labyrinth regions. If the opposite region is
generated, enable **Flip Side**.
